# Лабораторная работа №5

**Вариант №5:** Представление графа - матрица инцидентности. Реализуемый алгоритм - поиск минимального остовного дерева (алгоритм Прима).

Составить программу для нахождения минимального остовного дерева (МОД) в неориентированном взвешенном графе с использованием алгоритма Прима. Представление графа должно быть реализовано в виде матрицы инцидентности. 

Решение реализовать в виде набора подпрограмм: создание графа, добавление рёбер, вывод матрицы, выполнение алгоритма Прима, освобождение памяти. 

Ввод исходных данных осуществляется в текстовом формате: количество вершин и рёбер, затем описание каждого ребра (индексы соединяемых вершин и вес). 

Программа должна выводить исходный граф в виде матрицы инцидентности (строки - вершины, столбцы - рёбра, дополнительной строкой - веса рёбер). Результат работы алгоритма выводится в виде списка рёбер, образующих МОД (с указанием вершин и весов), и итогового суммарного веса дерева.
